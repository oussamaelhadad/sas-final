# SAS Progress Console

## Description

SAS Progress Console est une application console développée en JavaScript pour gérer les apprenants et suivre leur progression.

## Fonctionnalités

* Afficher la liste des apprenants
* Ajouter un apprenant
* Rechercher un apprenant
* Ajouter ou modifier un résultat
* Filtrer les apprenants par niveau
* Trier par progression
* Trier par ordre alphabétique

## Installation

```bash
npm install
```

## Lancement

```bash
node src/index.js
```
